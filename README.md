# 个人交易纪律台

按《个人交易策略与风险控制手册》完善修订版 V2.0（2026-11-19）做的网页。它计算能不能买、买多少、何时停、卖多少、禁买到哪一天。仓位、回撤、建仓比例和冷静期都可以在「规则参数」里改；每次保存生成新版本，V2.0 仍可切回去。

不连接券商，不自动下单。净值仍由手工录入。A 股价格可以从行情源填进成交和收盘，读到的价格要再点记录才会入账。

每个人注册后有自己的账本。用户名、密码哈希和登录会话放在 Redis；成交、计划和规则放在该用户自己的 SQLite 文件 `data/users/{用户号}.db`。旧的单用户文件 `data/td.db` 会在第一个注册用户建账时复制过去。

## 运行

先起一个开启持久化的 Redis：

```bash
mkdir -p data/redis
redis-server --bind 127.0.0.1 --port 6379 --appendonly yes --dir data/redis --daemonize yes
```

然后：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cd web && npm install && npm run build && cd ..
python -m td_api
```

浏览器打开 http://127.0.0.1:8765 。默认连 `redis://127.0.0.1:6379/0`，可用 `TD_REDIS` 改地址，用 `TD_DATA_DIR` 改账本目录。

## 行情

打开后第一页是看盘：搜索、自选、最近约 120 根日线，以及东方财富的涨幅、跌幅和成交额榜。自选名单存在用户账本里，不随行情源改变；自选报价固定用东方财富。正在看的报价、日线和榜单才走当前选中的源。刷新默认每 3 秒拉一次，可以改成 5 秒到 60 秒或关掉；页面切到后台就暂停。免费接口没有推送，这是能做到的实时。各源的报价都用同一套展示：最新、涨跌、成交额、开高低、昨收和 VWAP。K 线可切换分时、五日、日 K、周 K、月 K，拖动平移，滚轮缩放，十字线看价格和成交量。东方财富日 K、周 K、月 K 是前复权，新浪和 Tushare 是不复权；某个周期取不到时，图的位置和高度不变。点一只股票可以看报价，加入自选，或带到交易计划里建标的。读取前要在页面上选定一个行情源，选中的源失败不会自动改用另一个。新浪和未配置的 Tushare 没有榜单，只能搜索。可选：东方财富、新浪财经、Tushare。

Tushare 在设置 `TUSHARE_TOKEN` 之前会显示为未配置，选它会提示先填 token。配好后它仍只走 Tushare：先要实时日线，会员权限不够时退回 Tushare 日线。

开发时可以另开 `cd web && npm run dev`，页面在 Vite，接口仍由上面的进程提供。
